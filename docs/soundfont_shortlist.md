# SoundFont Shortlist

## Descargados localmente

- `soundonts/candidates/FreePats-Timpani-20240810/Timpani SF2-20240810/Timpani 20240809.sf2`
  - enfocado solo en timbales
  - primer candidato para comparar ataque, cuerpo y dinamica sin contaminarse con otros instrumentos
  - fuente: https://github.com/freepats/timpani/releases

- `soundonts/candidates/GeneralUser-GS.sf2`
  - GM/GS liviano
  - util para pruebas rapidas de latencia, mezcla y compatibilidad
  - para timbales en esta app, probar `bank 0 / preset 47`
  - fuente: https://github.com/mrbumpy409/GeneralUser-GS

- `soundonts/candidates/MuseScore_General.sf2`
  - GM grande con enfoque orquestal mas util que un GM chico para este proyecto
  - buen candidato base para comparar con el soundfont actual
  - para timbales en esta app, probar `bank 0 / preset 47`
  - fuente: https://ftp.osuosl.org/pub/musescore/soundfont/MuseScore_General/

## Otros candidatos para evaluar

- Aegean Symphonic Orchestra SND (sf2)
  - orquestal gratuito, pensado para repertorio clasico
  - compatible con bancos orquestales estilo MuseScore
  - fuente: https://sites.google.com/view/hed-sounds/aegean-symphonic-orchestra

- GoldMidi Symphony Orchestral Library / Symphony Orchestral GM
  - opcion comercial con timpani explicito en el banco GM
  - fuente: https://goldmidisf2.com/

## Orden recomendado de prueba

1. FreePats Timpani
2. MuseScore_General
3. GeneralUser-GS
4. Aegean Symphonic Orchestra

## Criterio de escucha

- ataque inicial del mazo
- cuerpo grave real en golpes medios y fuertes
- diferencia audible entre velocities
- cola / resonancia
- si el parche "corta" o suena plastico
