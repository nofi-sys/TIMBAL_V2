# Timbal UI skin assets

Optional 9-slice PNG assets can be dropped into `frames/`.

Expected frame files and margins:
- `board_9.png`: `48 48 48 48`
- `sidebar_9.png`: `32 32 32 32`
- `card_9.png`: `24 24 24 24`
- `nav_rail_9.png`: `32 32 32 32`
- `note_pad_9.png`: `24 24 24 24`
- `button_on_9.png`: `16 16 16 16`
- `button_off_9.png`: `16 16 16 16`
- `button_secondary_9.png`: `16 16 16 16`

When a file is missing, the skin falls back to painted/QSS gradients.
